# Aplicativos SilverByte para Windows

Baixe somente o aplicativo que deseja. **Não é necessário instalar o SilverByte Home, Python ou criar uma conta para usar estas ferramentas locais.**

| Aplicativo | O que faz | Download |
|---|---|---|
| **Citrino** | Geradores de números, nomes, códigos, listas, senhas e UUIDs. | [Baixar Citrino](https://github.com/SilverByteCompany/silverbyte-releases/releases/download/sb-generatebyte-latest-stable/Citrino-Instalador.exe) |
| **Jade** | Calculadora, cronômetro e temporizador. | [Baixar Jade](https://github.com/SilverByteCompany/silverbyte-releases/releases/download/sb-toolsbyte-latest-stable/Jade-Instalador.exe) |
| **Opala** | Conversões locais de imagens, arquivos compactados, dados, texto, cores e unidades, conforme as ferramentas disponíveis no aplicativo. | [Baixar Opala](https://github.com/SilverByteCompany/silverbyte-releases/releases/download/sb-convertbyte-latest-stable/Opala-Instalador.exe) |

Compatibilidade: Windows 10/11 de 64 bits. São versões iniciais em evolução. No Opala, conversão de PDF, áudio, vídeo e 3D ainda não faz parte destas ferramentas.

## Instalar e usar

1. Baixe o instalador do aplicativo escolhido.
2. Execute o arquivo e conclua a instalação.
3. Abra pelo atalho criado. As ferramentas acima funcionam sem internet.

Para uma instalação normal, basta baixar **o instalador**. ZIPs e manifestos das versões são utilizados pelo sistema de distribuição.

## Atualizações dentro de cada aplicativo

Cada instalação independente verifica seu próprio canal de atualização. A opção **Verificar atualização** fica na parte inferior da janela.

Quando existir uma versão nova, escolha **Baixar atualização** e depois **Instalar e reiniciar**. Salve seus resultados antes de confirmar. O aplicativo verifica a assinatura Ed25519 dos metadados e o tamanho e SHA-256 do instalador antes de executá-lo. As preferências ficam no armazenamento de dados de cada aplicativo.

Internet é necessária para baixar e atualizar, mas não para usar as ferramentas locais. O download de uma atualização corresponde ao aplicativo escolhido, não ao Home inteiro.

As cópias gerenciadas pela Biblioteca do Home continuam usando o atualizador do Home. Os instaladores desta página criam instalações independentes.

## Links permanentes e versões anteriores

Os três links de download acima continuam iguais quando uma nova versão é publicada. Podem ser compartilhados ou usados no site SilverByte. O histórico de versões fica em [Releases](https://github.com/SilverByteCompany/silverbyte-releases/releases).

Este repositório é público: os arquivos podem ser acessados e compartilhados por qualquer pessoa. O SilverByte Home e o beta privado são distribuídos separadamente.
